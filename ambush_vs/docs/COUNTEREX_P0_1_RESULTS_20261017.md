## 3. 摘要

**成立（软顶 ON）**：F-A30、F-A60、T-A−4、T-A+4、T-B+2、T-B+4、W-A-MG→Kar；警报 quiet / suspicious / area。

**不成立（软顶 ON）**：F-B30、F-B60、T-A−2、T-A+2、T-B−4、T-B−2、S-unscout-east、ALERT-global_alert。

**软顶影响**：OFF 时 BASE-B 从 win(伤 3) → lose(伤 6 / 全灭)；suspicious/area 不再有可胜案。故 **不能**靠关掉默认软顶来「修」朝向/时机门——会牺牲双解与警报可胜。对照仅测量。

## 4. 建议（本 PR 不硬改几何）

超过单 PR 范围；下一切片候选：

1. **F-B 朝向**：雷+MP+手雷已独立清场，Kar 偏 30°/60° 无差。收窄主路交叉走廊或削弱雷后残敌处理，使 Kar 扇成为必要带宽（会动金标）。
2. **A 时机 ±2 s**：杀伤窗过宽（甚至 +2 s 清场略快）。收紧纵队间距 / 侧翼入场与 t0 对齐，或加「发现窗」代价。
3. **B 早爆 −4/−2**：无雷手动仍可胜；需让侧翼未入时早开火必漏，或地雷是唯一可靠起爆器。
4. **未侦察东巷**：侧翼汇入主路后仍被谷仓 MG 清掉。应让侧翼可从 `east_alley` 脱出，或主路-only 布阵射界罩不住巷口汇合前。
5. **global_alert**：报警起爆后 A/B 皆负。若坚持 DEV_PLAN「每档 ≥1 胜」，需单独设计「警报后仍可打的残局案」；纸面 v1 只明确写了区域警戒。

本切片：**只加门与结果表**；规则默认与金标不变。
