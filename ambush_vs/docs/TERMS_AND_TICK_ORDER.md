三份 ADR 与院子纸面凡写「杀伤区 / 看到 / 暴露 / tick」一律以本页为准。

---

## 1. 伏击目标组 `ambush_targets[]`

- 关卡 JSON 字段：敌方 id 列表。
- 院子：主纵队 4 + 侧翼 2；**不含**岗哨、巡逻。
- `see_first_enemy` / `cross_marker` **只**对该列表内的存活敌人生效。

---

## 2. 杀伤区

起爆 tick 时，下列格的并集：

1. 各队员按**当前**站位/朝向算出的武器扇形中、**视线未被遮挡**的格；
2. 已放置地雷的触发格；
3. 计划手雷的落点作用格（布阵时指定，起爆后按武器节奏自动投出）。

「起爆时所有敌人都在杀伤区内」＝`ambush_targets[]` 中**已入场**者全部落在杀伤区格内；**未入场**者计为不满足。

---

## 3. 「看到」

与杀伤区同一几何：武器扇形（或视野锥）∩ 未遮挡格。灰色遮挡格不算看到。条件名 `see_first_enemy` 的判定对象是杀伤区，不是「任意视线」。

---

## 4. Tick 与时钟

| 项 | 值 |
|----|-----|
| 频率 | **20 Hz**（1 tick = 0.05 s） |
| 倍速 | 1×/2×/4× 只改播放，不改判定结果 / 日志哈希 |

### 4.1 每 tick 固定顺序

1. 输入  
2. 移动  
3. 地雷  
4. 视野 / 暴露  
5. 档位更新  
6. 起爆条件  
7. 开火  

**同 tick 内先升档、后判起爆**：本 tick 刚升到区域警戒或全图警报时，标准伏击已不可得。每 tick 日志至少记 `phase, alert, trigger`。

---

## 5. 暴露口径（警报升档）

- **全队合计**：某 tick 至少一名队员在至少一个发现锥内 → 计 1 tick（不乘人数、不按观察者分槽）。
- 连续 **30 tick（1.5 s）** → 起疑。
- **同一夜第二次起疑** → 区域警戒。
- 区域警戒期间再连续 **30 tick** → 全图警报。
- 计数**整夜保留**，不随侦察/等待阶段清零。
- **去掉**「3.0 s 累计暗槽」。
- 起疑后若离开锥且满足恢复条件 → 可回安静，但「第几次起疑」计数不重置。

图标表达档位（? / ?! / !），不做数值条。

---

## 6. 角度、距离、锥边界

| 项 | 约定 |
|----|------|
| 0° | 东；逆时针为正；90°＝北 |
| 距离 | 格心欧氏距离（1 格 = 1 m） |
| 锥 / 扇形 | **含边界**（距离 ≤ 锥长且偏角 ≤ 半角 即命中） |

---

## 7. 网格与高度

- VS＝**单层网格**；每格 `tier ∈ {ground, high}`；无上下叠格。
- 坡道对玩家仍属地面档（细则见 ADR-HEIGHT-01）。

---

## 8. 阶段枚举（避免与警报撞名）

`scout` → `setup` → `wait` → **`detonate`** → `sweep`  

禁止再用阶段名 `ALERT` / `alert` 表示「进入起爆」。警报档位用 `quiet|suspicious|area_alert|global_alert`。

---

## 9. 用户已拍板（2026-10-17）

1. 等待阶段**实时推进**（可暂停/倍速）。  
2. 起爆前：`ambush_targets[]` 行军敌人**无**发现锥；仅岗哨/巡逻有。起爆后所有敌人可索敌。  
3. 等待阶段每转 **45° 耗时 1.0 s**，期间不能开火；锥内转向按正常暴露计时。  
4. 区域警戒＝本页 §5「第二次起疑」方案。  
5. 当夜阵亡＝当夜失去该单位火力；跨夜受伤降档，无永久死亡。  
6. 起爆＝布阵设条件，到点自动执行；手动为备选。
