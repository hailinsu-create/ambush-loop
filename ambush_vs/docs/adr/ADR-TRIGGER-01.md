---

## 1. 背景

第一枪时机决定侧翼是否进杀伤区、前队是否离区。定位已定：布阵设条件、到点自动执行；手动非默认。

---

## 2. 决策

1. 布阵阶段选定**恰好一个**起爆条件；等待中条件首次为真的 tick 进入阶段 `detonate`，计划自动执行。
2. VS 必须支持的类型：`see_first_enemy` / `mine_detonate` / `cross_marker`；另有备选 `manual`。
3. **过滤（F1）**：`see_first_enemy` 与 `cross_marker` **只对** `ambush_targets[]` 中的敌人生效；岗哨、巡逻不触发起爆。
4. 新开局预选关卡 JSON 的 `default_trigger`（不把方案专属绑定写进本 ADR）。
5. 手动按钮可随时强制起爆；不作新局默认。
6. 阶段名用 `detonate`，禁止阶段枚举 `ALERT`（避免与警报档位撞名）。
7. 全图警报的 tick＝进入起爆，`trigger=alarm`（见 §3.4）。

---

## 3. 规则细则

### 3.1 条件配置（布阵）

| 项 | 规则 |
|----|------|
| 每局条件数 | 1 |
| `see_first_enemy` | 指定队员杀伤区内首次出现 `ambush_targets` 存活敌人（「看到」＝TERMS §3） |
| `mine_detonate` | 指定地雷爆炸瞬间 |
| `cross_marker` | 线段两端吸附格心；默认检测 **`ambush_targets` 头兵**中心越线 |
| 投掷物目标格 | 布阵指定；起爆 tick 后按武器节奏自动投出（进杀伤区定义） |
| 未设条件 | 布阵结束校验失败（除非显式 `manual`） |
| `default_trigger` | 关卡字段；新开局预选；T-06 仅在玩家主动清空时拦截 |

### 3.2 等待阶段

| 项 | 规则 |
|----|------|
| 时间 | **实时推进**；暂停；1×/2×/4×；倍速不改结果 |
| Tick | 20 Hz；求值顺序见 TERMS §4.1 |
| 转向 | 每 **45° 耗时 1.0 s**，期间不能开火；锥内转向按暴露计时（TERMS §5） |
| 静默 | 起爆前队员不射击 |

### 3.3 起爆瞬间与标准伏击

| 项 | 规则 |
|----|------|
| 进入 | 条件首次为真的 tick，或手动，或 `trigger=alarm` |
| 同 tick | 先升档后判起爆（TERMS §4.1） |
| 计划锁定 | 站位/朝向/武器/杀伤区/投掷目标不再改 |
| 控件 | 起爆（若未爆）、暂停、倍速 |
| 标准伏击 | 定义见 TERMS §2；且进入 `detonate` 的 tick **之前**警报从未达区域警戒或全图警报 |

### 3.4 全图警报 → 起爆（M5）

全图警报的 tick＝进入 `detonate`，`trigger=alarm`，计划锁定，队员按计划开火。已入场敌人就近找掩体；未入场敌人改走关卡 `alarm_route`。VS 阶段战斗队形只实现这两条。

### 3.5 伤亡与火力（已拍板）

- 当夜阵亡＝当夜失去该单位火力。  
- 跨夜：受伤降档，无永久死亡。

### 3.6 侧翼（院子初值）

主纵队头兵进门后 **+4.0 s** 侧翼进场。侧翼未到巷口就起爆 → 复盘主因「起爆过早」。

---

## 4. 不做

- 无条件纯倒计时默认开火。  
- 多段链式条件脚本树。  
- 起爆后改站位/朝向。  
- 把手动设为新局默认。

---

## 5. 验证用例

| ID | 场景 | 期望 |
|----|------|------|
| T-01 | 院子 A：`see_first_enemy` 绑 Kar@L；F1 进巷口杀伤区 | 该 tick 起爆；`trigger=see_first_enemy`；岗哨/巡逻不触发 |
| T-02 | B：`mine_detonate`；敌人踏雷 | 爆炸 tick＝起爆 tick |
| T-03 | `cross_marker`；头兵越线，**侧翼尚未到巷口 (18,8)** | 起爆；侧翼未在杀伤区 → 逃脱或主因「起爆过早」 |
| T-04 | 相对最佳 +4 s | 前队离区或发现风险；主因「起爆过晚」类 |
| T-05 | 已设条件，等待中点手动 | `trigger=manual` |
| T-06 | 玩家清空条件后点开始 | 校验拦截 |
| T-07 | **无手动输入的回放**；1× vs 4× | 起爆 tick 与日志哈希一致；有手动则按 tick 戳入日志 |
| T-08 | 全图警报 | 进入 `detonate`，`trigger=alarm`；标准伏击失败 |

## 6. Changelog（相对草案）
