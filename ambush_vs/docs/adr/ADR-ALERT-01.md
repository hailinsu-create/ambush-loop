---

## 1. 背景

被发现须有可预期代价且不直接判负。灰盒：视野锥 + 头顶图标，无数值条；预览＝模拟。

---

## 2. 决策

1. 四档（全局最高档生效）：安静 → 起疑 → 区域警戒 → 全图警报。  
2. 确定性计时；不掷骰子。口径见 TERMS §5。  
3. **起爆前**：仅岗哨/巡逻有发现锥；`ambush_targets[]` 行军敌人**无**锥。起爆后所有敌人可索敌（M1）。  
4. ×1.5 剪影距离对**所有敌方发现锥**生效（含巡逻）。  
5. 被发现不直接判负；院子区域警戒后 A/B 至少一案仍能胜。  
6. 区域警戒的「标红」＝预告 `alert_route` 锥覆盖（M4），非暗标签。

---

## 3. 规则细则

### 3.1 档位与行为

| 档位 | 敌方行为 | 玩家可见代价 | 标准伏击 |
|------|----------|--------------|----------|
| 安静 | 原路线；常态锥 | 无 | 可得 |
| 起疑 | 最近岗哨/巡逻转头查看；满足恢复则回安静 | 头顶 ? | 仍可得（未再升级） |
| 区域警戒 | 相关巡逻切到关卡 `alert_route`，锥覆盖 `threatens_slots`；站其上的队员按正常暴露计时 | 预告标红＝该锥覆盖；图标 ?! | **不可得** |
| 全图警报 | 进入起爆 `trigger=alarm`（ADR-TRIGGER §3.4） | 图标 ! | **不可得** |

### 3.2 计时（替换草案 3.0 s 累计）

见 TERMS §5。初值：

| 参数 | 初值 |
|------|------|
| 连续暴露 → 起疑 | **30 tick（1.5 s）** |
| 同夜第二次起疑 → 区域警戒 | 事件次数（非整夜累计秒暗槽） |
| 区域警戒下再连续暴露 → 全图警报 | **30 tick（1.5 s）** |
| 起疑恢复 | 转头 **4.0 s（80 tick）** 且锥内无队员 → 回安静；「第几次起疑」不重置 |
| 高点剪影 | 发现距离 ×1.5（ADR-HEIGHT）；计时阈值不变 |

20 Hz；倍速下 tick 数与哈希一致。

### 3.3 视野与预览

| 项 | 规则 |
|----|------|
| 看见 | 锥角/锥长内（含边界）且视线未挡；高度见 ADR-HEIGHT |
| 「点地面」 | 与模拟 100% 一致 |
| UI | 橙锥；四档图标；无数值条 |

### 3.4 威胁槽约束（F3）

- 每个岗哨/巡逻声明 `threatens_slots[]`。  
- **每个 `threatens_slots` 集合最多只能使一个基准方案失去关键位**；关卡校验脚本必须断言。  
- 院子：门楼威胁矮墙台 L（动 A）；巡逻威胁西矮掩（动 B）——分属不同集合。  
- 标红＝提前预告 `alert_route` 锥将覆盖这些点。

### 3.5 与起爆衔接

- 安静/起疑下条件可正常触发。  
- 区域警戒不自动开枪；标准伏击已不可得。  
- 全图警报＝`trigger=alarm` 进入 `detonate`。

---

## 4. 不做

- 概率发现、怀疑度数值条、「被看见＝立即失败」。  
- 与预览不一致的隐藏修正（除写明的 ×1.5）。

---

## 5. 验证用例

| ID | 场景 | 期望 |
|----|------|------|
| A-01 | 锥内连续 30 tick | 起疑；日志 `suspicious` |
| A-02 | 起疑后离开，80 tick 内不再见 | 回安静；起疑次数保留 |
| A-03 | 同夜第二次起疑 | 区域警戒；`alert_route` 生效；标准伏击 false |
| A-04 | 区域警戒下再连续 30 tick | 全图警报；`trigger=alarm` |
| A-05 | 「点地面」：**全部可站立格** | 预览＝模拟 |
| A-06 | 院子区域警戒后跑 A 与 B | 至少一案仍胜 |
| A-07 | 全图警报后通关 | 可胜负，标准伏击失败 |
| A-08 | 1×/4× | 升档 tick 与哈希一致 |
| A-09 | 高点 ×1.5 | 存在距离 D：地面不在锥、高点在锥 |
| A-10 | 校验：任一 `threatens_slots` 集合 | 最多废一个基准方案关键位 |
