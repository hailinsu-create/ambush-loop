| 字段 | 值 |
|------|-----|
| 状态 | **已采纳 v1（2026-10-17）** |
| 日期 | 2026-10-17（自 2026-10-16 草案） |
| 决策域 | 两档高度与射界/发现 |
| 依据 | 定位页、规划 D3、Opus 复核 M7/次要项 |
| 关联 | [TERMS_AND_TICK_ORDER](../TERMS_AND_TICK_ORDER.md)、ADR-ALERT-01 |

---

## 1. 背景

陌生人须能指出占高点在射界上的可见差别。两档可读；价值画进灰色遮挡；无隐藏命中/伤害倍率；有剪影与上下耗时代价。

---

## 2. 决策

1. 玩家规则只有 **地面 / 高点**；格子属性 `tier ∈ {ground, high}`（TERMS §7）。  
2. 坡道＝地面档，移动中不能开火。  
3. 高点恰好三条可见效果：扇形灰色缺口更少；夜间剪影发现距离 ×1.5；上下各 +2.0 s。  
4. 无隐藏命中/伤害/压制倍率。

---

## 3. 规则细则

### 3.1 格子类型

| 类型 | 玩家档位 | 移动 | 开火 |
|------|----------|------|------|
| 地面 | ground | 可 | 站定可 |
| 坡道 | **ground** | 可；**移动中不能开火** | 站定且地面档视线 |
| 高点 | high | 可；入/离 **+2.0 s** | 站定可 |

VS＝单层网格，无「正下方叠格」。内部若用连续插值，不得对玩家暴露为第三档。

**攀爬（入/离高点的 +2 s 段）**：期间算 **ground** 档、**不能开火**、暴露按**出发格**计。

### 3.2 视线与射界

| 项 | 规则 |
|----|------|
| 低掩体 | 只挡同层（ground↔ground） |
| 高点 → 低处 | 低掩体不挡；院子验收：高点缺口面积 \< 同射手地面的 50% |
| 高点 → 高点 | 按关卡实心墙/`#`；矮掩体不挡 |
| 表现 | 被挡＝灰色阴影；唯一正面表现 |

### 3.3 夜间剪影

| 项 | 规则 |
|----|------|
| 开关 | 关卡字段 **`night=true`**（VS 六夜全部 true） |
| 效果 | 对高点队员做锥判定时，**所有敌方发现锥**有效距离 × **1.5** |
| 计时 | 升档阈值仍用 ADR-ALERT / TERMS |
| 可读 | 高点剪影/黄描边；「点地面」须反映 ×1.5 |

### 3.4 上下耗时

| 项 | 初值 |
|----|------|
| 进入高点 | 正常移动外 **+2.0 s** |
| 离开高点 | **+2.0 s** |
| 坡道 | 无 +2 s；移动中不能开火 |

### 3.5 排除

无 `height_damage_mult` 等字段；无高点护甲/暴击优待。

---

## 4. 不做

- 向玩家暴露连续高度或第三档。  
- 高点隐藏命中/伤害加成。  
- 纯装饰高点。

---

## 5. 验证用例

| ID | 场景 | 期望 |
|----|------|------|
| H-01 | 同朝向：谷仓高点 **(5,9)** vs 邻格地面 **(6,9)**；主路有低掩体 | 高点灰色缺口 \< 地面 50% |
| H-02 | 坡道站定开火 | 允许；地面档视线 |
| H-03 | 沿坡移动的 tick | 该单位不能开火（敌人同理若适用） |
| H-04 | 地面→高点 | 日志含 +2 s；完成前不在 high；攀爬段 ground/禁射/出发格暴露 |
| H-05 | 高点 vs 地面对同一锥 | 存在 D：地面不在、高点在（×1.5） |
| H-06 | 同无掩体目标伤害 | 与武器表一致，无高度乘区 |
| H-07 | 盲测 | 教学不提示「占高点」；扇形阴影可辨 |
