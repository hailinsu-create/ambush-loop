# PR15 独立环境资产工作包接口

日期：2026-10-02。状态：主集成者提出可独立制作包，供 dot 分配；尚未派遣、生产或验收。继承 PR14 `d69251be42d5f96c99da48a24a3923b62863f28f` 详单与14类原资产 inventory，按 v2 先完成制作、六关接入和云端验证，之后再讨论设备。

## 所有权与交付

建议独立工作者仅拥有新目录 `ambush_loop/ArtSource/environment_v2/` 和 `ambush_loop/art/environment_v2/`，在独立分支提交固定候选。保留已有 `ArtSource/v2/build_yard_kit.py`、yard/actor atlas、角色/武器GLB、音频制作目录及全部运行代码原字节。不要改共享 `art/v2/manifest.json` 或 loader；可交候选台账 `ArtSource/environment_v2/catalog_candidate.json`。主作者按验收结果逐件采用，不整体合并。

世界一格一米，Godot +Y向上/-Z向前；模块根在地面中心，地面顶面Y=0。现有40×22格的逻辑阻挡和LOS仍唯一决定规则，所有网格是 `visual_only`。拆分门、箱盖、屋顶和可观察外墙仅为显示动作/遮挡，不自行加导航、碰撞或高度收益。

每件独立、稳定 `asset_id`，路径建议 `art/environment_v2/models/<asset_id>_lod<n>.glb`；普通道具/建筑至少LOD0/1，纹理使用本包独立albedo/normal/ORM，材质槽 `environment_v2_atlas`，必要发光槽单列。每件记录尺寸、原点、前向、各LOD的三角面/surface/真实SHA-256、骨/活动节点或插槽本地变换、来源/使用条件、固定工具及源文件。ORM通道明确，禁止烘焙方向性光照进albedo。主作者后续扩展运行loader，不要求该工作者编辑它。

## 分批清单

1. **院子环境成套**：现有五类基准道具之外，完整内外墙/角/门窗/可拆屋顶/矮墙/围栏；真实仓库出入口；混凝土、泥土、砖石/金属地表与少量接缝杂物。八方位、35°/65°及近远都完整，不能以一段仓库或固定角度图交付整个院子。暖灯挂点声明即可，照明预算由运行作者控制。
2. **14类原用途覆盖**：`ammo_can/barbed_wire/fence_section/field_radio/gun_case/handcart/jerry_can/lamp_post/oil_drum/rations_crate/sandbag/spare_tire/wooden_barrel/yard_crate`。按上述固定inventory逐行映射原用途到新asset_id，记录已复用基准件和真实新制件；枪与手持工具由R2角色包拥有，重叠用途仅复用，不再生产冲突副本。开合/取物节点单列，地面拾取和交互类别不得仅靠台账写完成。
3. **其余五关主题套件**：仓道棚架、泵站设备、信号楼桅杆、油库罐群、电台天线；交付逐关独立的主地标、地表/围墙组合和可从背面辨认的结构。共享建筑可复用，但不能以复制摆件声称五关完成。关卡摆放映射/运行验证仍归主集成者。

保持普通道具通常200–2000三角面、1–2surface；建筑通常0.5k–5k并共享材质。预算是云端工程起点，不能写成安卓性能通过。独立环境atlas避免改动现有共享纹理；需要调整预算时给出具体几何/视距理由。

## 验收与接入门

源文件、可复跑导出和依赖/来源说明；两次独立导出的真实内容与哈希一致性；GLB/纹理结构报告；实际Godot4.7.2导入、尺寸/LOD/material/socket检查；中性与暮色、八方位及俯角/缩放两端精选图片；动作节点若存在须有实际录屏。错误/未验项逐条列出，样本转台不替代战场验收。

主作者采用后负责asset→逻辑用途映射、摆放、遮挡、灯光、运行manifest与导出包含；实际SCOUT→ALERT→SWEEP、回放/重试、六关视觉和行为不变量、云端性能与可追溯APK。最终美术、整场视觉、设备和声音品质分别验收，不合并不同门槛。
