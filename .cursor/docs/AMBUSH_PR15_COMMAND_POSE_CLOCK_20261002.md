# PR15 SWEEP 动作时钟补片

2026-10-02，dot 对 a3e6e2 实战复验报告 SWEEP 的旧 fire 常驻与近期 death 停帧。已优先暂停环境组装，在当前 R4 + 环境资源固定源 e0f50dd 实际重跑首波到 SWEEP、scout 合法移动四格与真实死亡骨骼。旧 fire 在 R4 格式2已取消；death 仍只用停住的 sim tick。新的实际反例 19 项/8 fail，退出1，包含跨命令时间历史样本不变以及旧格式1的 fire/death；测试首轮类型推断错误另留日志，不计行为反例。

目标：命令与结果阶段使用独立表现时钟，只改变显示及暂停菜单/应用离开时的既有冻结意图；事件年龄以记录的 battle→command 锚点延续，不更改 sim tick、事件身份、波偏移或战斗数值。记录可选事件年龄格式1及显式时钟，暂停、2×、回放/seek不借当前活体时间。旧 command 记录没有锚点则结束 death、取消旧 fire，不编造过去时长。

实施后验证实际 main/3D 骨骼、合法 SWEEP 移动/暂停/恢复/后台、复制历史前后采样、无活体回写，针对枪族/实战/HUD/生命周期/六关与时间轴回归。完整 command 时长在时间轴上的独立区段仍属版本化全3D回放后续，不把逐记录可重现称完整已接入。
