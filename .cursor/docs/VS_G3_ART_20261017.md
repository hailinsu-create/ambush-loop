## 可读性抛光（相对 yard_concept）

已确认问题：wait 仍像扁平蓝灰盒（G1 式灰/绿块洗掉贴图）。本切片改动：

1. **G3 无实体层级填充**——高地用屋面/墙顶贴图 + 落影 + 细边；可见性仅锥/扇区轮廓 + 楔形淡色（≤15% α）；「点地面」预览仍可高亮格
2. **世界空间 UV**（约 4 格/贴图）+ 材质分流提亮（泥褐/草绿/石板灰）+ 更轻月光/暗角
3. **建筑**：高地 slate/shingle 脊线与檐影；structure 用 shed_roof 道具
4. **单位** ≈1.6× + 软落影 + 全队黄环
5. **灯笼**更小、更暖、仅 3 处

### 续修（建筑物 / 沙袋 / 氛围）

1. **建筑物**：墙体/高地/structure 一律 slate/shingle 屋面；去掉纹理内 eaves 条带（防世界 UV 横纹）；足迹脊线+地面檐影+轮廓
2. **沙袋**：props 精灵交错堆叠；仅 cover 外沿连线（避免地毯格）
3. **去调试感**：G3 不画 threat_slot 红 X / high_edge 黄框
4. **氛围**：地面略压暗；2–3 处暖灯笼

### 续修（clip + 地面映射）

1. **扇区裁剪**：`MapHost` → `SubViewportContainer`/`SubViewport` 硬裁切；楔形点钳制到地图矩形（不再盖住右侧 UI）
2. **石墙不再铺满地面**：`stonewall` 仅墙格窄条+投影；厚墙体用暗色体块；开阔地以泥+草为主，鹅卵石留给道路/`=`
3. **高地 footprint**：`high_slots` 脊线+地面檐影
4. **沙袋**：仅 `low_cover` 格，邻接合并为连续带并填满格高



### Round 7（沙袋精灵表 + 去草泥格色块）

1. **沙袋**：`assets/g3/src/sandbag_sheet_magenta.jpg` → pipeline 抠品红+紫边 despill/erode 切 straight×3 / L / T / end / round；灰盒按 cover 沿铺（高≈0.45 格），去黄木条胶囊；夜色 modulate + 落影
2. **草/泥**：草区连续填充 + 近同色月光 modulate + 软区 wash（去掉方格边条），压掉右侧方格色块

### Round 6（细鹅卵石 / 沙袋堆 / 屋体檐面）

1. **鹅卵石**：`G3_COBBLE_CELLS=1.5`（约 6–8 石/格）；地面按行连续 world-UV + 统一月光 modulate；邻接材质软混合带
2. **沙袋**：盖沿连线改为可读堆——袋长 ≈0.45 格、2 行交错、麻袋色+暗缝+落影
3. **建筑**：南向墙面/檐影；灯笼同时照屋顶与地面；屋面 texel 略放大（`G3_ROOF_CELLS=5.5`）

### Round 5（围墙院子，非屋面海）

相对 Round 4「~60% 屋面」过修：

1. **分类 blocked**：贴边墙连通块 → 夜色泥/草 + 暗角；**仅** high/structure 紧凑屋体（院内 2–3 栋）画屋面+脊线+檐影+灯笼
2. **干砌石围墙**：沿院子边界连续窄条（~⅓ 格，顶高光+落影）；内部分区墙同为窄条，非填格
3. **无格缝**：地面按区域连续 world-UV 填充；屋面按行连续采样；`G3_TEX_CELLS=12`
4. **地面分区**：鹅卵石院心、泥径、草圃；冷月光 + 屋顶暖灯
