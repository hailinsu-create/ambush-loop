## 接入范围

以本地院子网格为唯一玩法权威，为院子增加单独的 3D 预览场景与返回 2D 的按钮；项目默认启动和原 2D 场景保持不变。可从 Godot 编辑器运行 `ambush_loop/scenes/presentation/yard_i0_3d.tscn` 体验候选场景。

表现层使用本地高度格将单位、阻挡物与地面拾取候选映射到 3D；3D 命中仅返回候选逻辑格/稳定单位 ID，再交给现有的选择与触摸意图流程。点选队员只选择，不直接发移动。HUD/现有 2D 布局、移动寻路、坡道通行、高度视线、战斗结算、资源和弹药记账仍由原逻辑处理。取消意图会清理对应 3D 预览。

仅挑选院子预览实际用到的四种原创环境模型与材质/贴图，未合并 PR #15，也未搬入六关全套表现运行框架。固定来源、Git blob 核验与授权说明见 [素材来源记录](../../ambush_loop/art/environment_v2/M2_I0_SOURCE.md)。渲染预览为 [M2-I0 院子截图](evidence/20261005-m2-i0-yard-preview.png)。
