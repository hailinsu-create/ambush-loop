## 范围

解决移动/掩体意图确认条固定在右下角、手指离目标太远的问题：把预览目标投影到活动渲染器的屏幕坐标，将确认条放到安全区内、靠近目标且避开现有 HUD 覆盖。此记录只覆盖 P2 的就近确认，不代表朝向手柄、镜头回中/缩放、上下文搜索或完整 P2 已完成。

- 分支：`codex/m25-p1a-tactical-data`
- 基线：P1B 展示与扩展门已提交；当前 P2 源码变更尚未提交。
- 不改移动、射击、搜索、资源消耗、游戏阶段或存档规则。

## 实现

1. 新增纯屏幕布局助手 `ambush_loop/scripts/ui/touch_intent_layout.gd`：使用目标周围候选位置，在传入的安全区内选择与目标最近、且不压住障碍物的面板位置；没有可用邻近位置时回退到安全区内、底部操作栏上方。
2. `touch_hud.gd` 的确认面板由固定右下锚点改为顶左坐标定位；预览启动/更新时重新布局。保留确认与取消为独立 UI 控件，不将面板标签穿透成地图指令。
3. 2D 意图用 Canvas 坐标转换；选择 3D 院子时使用当前相机 `unproject_position`，并拒绝视锥外/背后/屏幕外的目标。
4. 避让提示文字、队员头像卡、3D 返回按钮和战术信息卡；将系统安全区、左右边界和底部命令栏计入可放置范围。
5. 计划位置仅跟随当前预览意图，不改变既有触摸代次、显式二次确认或取消语义。
