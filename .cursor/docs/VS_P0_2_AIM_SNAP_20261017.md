## 目标

让手指能摆出 ±5° 级方案：拖方向柄时放大镜 + 有意义吸附；G.1「站位 ±1、朝向 ±5° 仍赢」在角色合法格上成立；P0-1 反例门（偏 30°/60° 仍输）保持。

## 已实现

1. **放大镜**：`greybox_map` 拖柄时弹出 loupe（触屏/鼠标），偏移离开指尖；松手/取消消失。
2. **吸附**：`AimSnap` — 北门 / 南门 / 巷口 / 路口 / 杀伤区边界（半角）在 ±7.5° 内吸附，否则 5° 步进。提示仅用中性名称。
3. **容差门**：`w2_aim_tolerance_test.gd`（见结果表）。
4. **W8**：吸附数学 + 放大镜出现/消失 + 松手只提交一次转向（293 断言）。

| 层 | 规则 |
|----|------|
| 必过 | 出版站位 × 朝向 ±5° |
| 高点 | 同 `high_slot` 内 ±1；偏格重瞄意图地标（巷口等）再 ±5° |
| 地面有盖 | 同 cover-pad（家有 cover 的 ±1 邻居也须有 cover）；B Kar → 路口 |
| 开阔地 | 全 ±1 × 出版朝向 ±5° |

结果：`passed=111 failed=0`。遗留：cover-pad 外格不纳入 G.1（文档化，非门失败）。
