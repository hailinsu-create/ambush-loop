## 1. 决策摘要

建议整合协作者的原创 3D 表现资产和表现层，但不整包合并 PR #15。以本地已验证的战术规则为底座，先做院子最小接入，再完善两种伏击打法；其余五关资产作为候选留给 M3。推荐默认固定斜俯视，旋转仅为可选观察操作，不把自由镜头变成必学步骤。真实 3D 是对旧方案“2D 逻辑+烘焙图”的建议调整，不是重写模拟，也不是本轮已获实现验收。

玩家目标仍是：观察威胁 → 选择补给路线 → 占高点或地面设伏 → 发动短促交战 → 看懂结果 → 快速改方案。三人分工、真实射线、有限弹药、ALERT 部署冻结与只读复盘保留。不添加实时走位、潜入追击网、第七关或联网。

## 3. 为什么不能整体覆盖

1. 高度契约未接通：协作 world_space.gd 的 logic_to_world 默认 height=0；world_picker_3d.gd 先与 y=0 平面相交，目标 AABB 也由无高度参数的 logic_to_world(item.pos) 创建。不能据此认定高台、坡道、台上人物和地面拾取已对齐本地规则。必须扩展表现数据与拾取契约，不允许改真实射线来迁就画面。
2. 输入有两个入口：协作 main 接 presenter.handle_unhandled_input 和 pick_at，本地 T1/T2 管理意图预览/确认/取消。二者并列处理可能重复消费、旋转松手误走位或取消后残留；必须唯一命令入口。
3. 快照与回放差异大：协作有历史表现快照/动作时钟/FX 池。本地高度、资源和将来的触发 tick 必须带版本进入记录，回放只能读当次记录，不能读当前场景替代过去。
4. 工程设置、字体、音频和隔离 runner 都有分叉。不得用协作配置覆盖已验证隔离和本地内存修复；云端软件渲染指标不能证明手机性能或 AudioTrack 已修复。
5. PR15 含大量资产、证据和多轮历史。保留原 PR 及完整作者证据，不批量复制旧日志进每个新切片；新证据必须指向整合后的精确候选。

## 5. 重排后的 M2 路线

以下为建议替代执行顺序，保留原 A–F/T 编号以便追溯，不重做已通过的 A/B1/T1/T2。

| 顺序 | 切片 | 玩家能得到什么 | 可验证出口 |
| --- | --- | --- | --- |
| 1 | M2-I0 整合契约与院子竖切 | 同一个院子规则能用候选 3D 显示；有关闭 3D 的开发回退 | 固定双方 SHA/资产清单；一个高台+坡道+三人+箱子；高/低点选择正确；2D/3D 相同指令的终局、HP、弹药和事件一致 |
| 2 | M2-T3 合并后的触屏收口 | 点选清楚，先预览再确认，旋转不误走位 | 单输入所有者；48×48 Godot 逻辑像素有效热区；1280×720、960×540 合成横屏；UI 无穿透/遮挡/隐藏热区；取消与迟到事件安全；实际支持尺寸在实现时核对 |
| 3 | M2-B2 单次主接触与两种打法 | 高点交叉火力与地面爆破合围真正不同 | 保留 B1 资源守恒；主路/延迟侧翼同次接触；一案不上高台；资源/路径/触发至少两项不同；各有成功、反例及邻近合理部署容错 |
| 4 | M2-D1 快速修改方案 | 失败后回到本次开战前，不反复搬弹药 | 会话内快照含库存/弹药/工具/位置/方向；连续十次恢复无增殖；敌人、掉落、事件、表现池全部清理；目标恢复控制≤5秒，需实测 |
| 5 | M2-C 同步发动实验 | 看懂谁能参战、何时发动；不用忙着点人 | 先预设触发线，再独立试一次手动全队开火；冻结不变；固定 tick 记录，1×/2×同 tick 同结果；无真人对比前默认保留自动触发基线 |
| 6 | M2-E 院子完整视听与复盘 | 看清高台、坡道、敌人、出口，交火与复盘可解释 | 同候选实装截图/遮挡与点击/动作事件一致；3D 回放只读；暂停/倍速/重试时钟正确；字体/内存/音效有界；来源许可完整 |
| 7 | M2-F 引导与阶段验收 | 首次能独立完成一场短伏击 | 四步可操作引导；继续/恢复；五人至少四人独立发动有效伏击并能解释高点取舍；手机触控/稳定性/音频/性能另验 |

为什么先 I0：用最小场景发现高度与输入接缝，避免 T3 在两套 HUD 上重复做。I0 不升级全六关，不追求最终艺术，不串入新战斗规则；它不是数周美术重构。如果接缝成本过高，保留资产，停在适配边界，以本地 2D 继续 B2/D/C，不让游戏设计等待全套 3D。

为什么 D 提到 C 前：快速恢复可降低对比两种发动方式的重复操作成本，先证明“改方案”顺畅，再研究新的时机交互。B2 先以现有发动语义建立内容基线；手动开火只是 C 的候选，不用它回头宣称 B2 已通过。

## 8. I0 四项接口门与明确停止条件

- 高度：仅由本地 grid.gd 的 elevation_tier/ramp_links/height LOS 提供权威高度。地面/台上各一名队员、坡道、地面箱与高台测试箱应保留相同逻辑锚点；禁止无坡上台，绘制不改射线。高台箱可作为隔离测试夹具，不能把旧 M1 的 SMG 箱误称为当前 B1 正常关卡补给，也不能为测试改四处生产补给。
- 拾取：3D 返回实体 ID/箱子 ID/逻辑格或纯镜头目标，再由原命令入口校验。测试高台、台下/背后、装饰物、不可达高面、重叠目标的确定性选择；不得在 presenter 直接给资源或移动单位。
- 输入：HUD 优先消费；presenter 只分类镜头操作或返回拾取候选，本地意图系统唯一决定世界命令。继承 T1/T2 的确认、取消、迟到事件隔离；不得形成两条执行路径。
- 资源：接入测试证明识别目标仍经原拾取路径；复用 B1 定向门核实 1/3/1 → 7/50/6、可选手雷未被强取、重复拾取/换枪不造弹。不要把旧测试夹具当成新关卡内容。

差分比较固定字段：phase/outcome、单位逻辑位置/格、HP/alive、装备、弹药池、工具、箱子收集状态、敌人状态、战斗事件语义。排除镜头变换、渲染对象 ID、动画/表现时钟、FX 池和插值；同一原始命令序列必须用于两种表现模式。
