# PR15 历史画面快照格式 1

日期：2026-10-02；源码 `17aba59df7a4ddd5c98986f12c07125d0bed8190`。这是历史数据和灰盒表现接缝，不代表角色、完整 HUD 或全部 3D 特效接入完成。

## 格式与所有权

BattleLog 的时间/身份格式仍为 schema 2；snapshot.data.visual_schema = 1 为独立的历史画面格式。attempt/wave/seq/event ID 和全局 timeline_tick 沿用先前修复。模拟 60 Hz、路线、伤害、冻结、胜负没有改动。

VisualSnapshot 只读取模拟节点并复制普通值。对象 ID 来自表现层私有登记表：同一 attempt/关卡中的对象保留 ID，移除对象后不会复用；换 attempt/关卡清理登记表。登记表不写节点、碰撞或战役数据。人物仍使用逻辑 actor ID，身份由记录的 attempt/wave 限定。

| 数据 | 已记录的字段 |
| --- | --- |
| 世界 | 关卡 ID、blocked 地图、逃逸口、门锁、阶段、选中队员、掩体位置/朝向 |
| 队员 | 位置/朝向/可见/存活/HP/弹药/角色/实际武器；移动、匍匐、奔跑、阴影、搜索/时间、搬运；开火冷却/间隔/模式、冻结、弹池、背包、雷/地雷/诱饵数及自动雷/标记；射界和基础动作描述 |
| 敌人 | 位置/朝向/可见/存活/HP/路线、移动/警觉/还击/回波、目标 ID 和基础动作描述 |
| 哨兵 | 位置/朝向/可见/倒地、状态、怀疑、冻结、射界与基础动作描述 |
| 场景对象 | 箱子种类/数量/搜索进度；掉落种类/数量；油桶/绊索/雷的 armed/spent；手雷型号/起点/目标/飞行/引信；诱饵寿命/时间 |

ViewState 在 REPLAY 只读取当前历史快照；世界布局、选中队员定位、武器、敌人朝向、姿态及对象不再借用活体字段。传出的数组/字典递归只读并与原快照分离。灰盒新增工具/油桶代理与历史匍匐比例；尚未用人物动画、武器成品或完整特效替换这些代理。

## 兼容

没有 visual_schema 的旧单波/单调记录保留原有角色值；缺武器、动作、世界布局和选择时提供中性默认，不取当前关卡补写。界面提示旧记录。没有历史选择的“定位选中队员”拒绝定位活体。未知未来格式保留原记录、显示不支持提示，并拒绝按当前格式解释画面。

旧多波记录缺波次边界且 tick 回退的情况沿用时间接缝的明确拒绝，不声明已经恢复迁移。没有全套历史信息时也不声明旧记录可完整还原。
