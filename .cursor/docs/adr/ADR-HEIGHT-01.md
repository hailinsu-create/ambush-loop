# ADR-HEIGHT-01 高度规则

| 字段 | 值 |
|------|-----|
| 状态 | **草案待审** |
| 日期 | 2026-10-16（Asia/Shanghai） |
| 决策域 | 玩家可读的高度与射界/发现 |
| 依据 | [玩法定位](https://app.notion.com/p/3fab407a692a819883aad3c16554c4b7)、[开发规划](https://app.notion.com/p/41d1a402652d49548f2fc51ee325271b) D3、[讨论](https://app.notion.com/p/3fab407a692a806b96acd47228c94e8e) |
| 关联 | ADR-ALERT-01（剪影发现距离）；成功标准「为什么要占高点」 |

---

## 1. 背景

陌生人首局成功标准第 1 条要求玩家能指出**占高点在射界上的可见差别**。定位要求：玩家面对**两档**可读规则（地面 / 高点），不做隐藏高度数值；高点价值画进扇形灰色遮挡；**不加**隐藏命中/伤害倍率；高点有可见代价（夜间剪影、上下耗时）。

规划 D3 推荐：坡道算地面且移动中不能开火；高点三条可见效果——扇形缺口更少、夜间剪影发现距离 ×1.5、上下高点 2 s。

工程上 CB2 曾用连续坡道插值，仅作素材；本 ADR 以定位与规划为准重写玩家规则。

---

## 2. 决策

1. **玩家规则只有两档：地面 / 高点。** 格子类型对玩家展示为这两档；不展示「海拔米数」或连续插值系数。
2. **坡道 = 地面**，且 **移动中不能开火**（含沿坡移动的整段）。
3. **高点恰好三条可见效果**（VS 内写死，不加第四条隐藏加成）：
   - 射界扇形被低掩体挡住的灰色缺口**更少**（高点看低处时低掩体不挡）；
   - **夜间剪影**：岗哨对高点单位的发现距离 × **1.5**；
   - **上下高点各耗时 2 s**（进入/离开高点格的移动附加时间）。
4. **高点不加隐藏命中/伤害倍率**，也不加隐蔽的暴击/压制数值优待。

---

## 3. 规则细则（含初值）

### 3.1 格子类型（玩家可见）

| 类型 | 玩家档位 | 移动 | 开火 | 备注 |
|------|----------|------|------|------|
| 地面 | 地面 | 可 | 可（站定） | 含平地 |
| 坡道 | **地面** | 可，但**移动中不能开火** | 仅站定且视为地面档视线 | 不向玩家暴露中间高度 |
| 高点 | 高点 | 可；**进入/离开附加 2 s** | 可（站定） | 黄描边等可读标记 |

内部模拟若用连续高度插值，不得在 UI/复盘中暴露为第三档数值。

### 3.2 视线与射界（可见效果 ①）

| 项 | 规则 |
|----|------|
| 低掩体 | 只挡**同层（地面↔地面）**视线与射界 |
| 高点 → 低处 | 低掩体**不挡**；扇形中灰色缺口面积应明显少于同位置地面（院子验收：高点缺口面积 \< 地面同射手缺口的一半） |
| 高点 → 高点 | 按关卡掩体高低标记；VS 院子以纸面关卡为准 |
| 表现 | 被挡部分 = 灰色阴影；这是高点价值的**唯一**正面表现方式（无「+命中」飘字） |

### 3.3 夜间剪影（可见效果 ②）

| 项 | 初值 |
|----|------|
| 适用 | 夜间关卡中，站在高点档的队员 |
| 效果 | 对该队员做「是否在视野锥内」判定时，锥的**有效发现距离 × 1.5**（或等价：该目标对锥长度判定放大） |
| 计时 | 升档秒数仍用 ADR-ALERT-01（1.5 / 3 / 2 s），只改「能否被算进锥内」 |
| 可读性 | 高点单位有剪影/描边提示；侦察预览「点地面」须反映 ×1.5 后的结果 |

### 3.4 上下高点耗时（可见效果 ③）

| 项 | 初值 |
|----|------|
| 进入高点格 | 在正常移动时间外 **+2.0 s** |
| 离开高点格到地面/坡道 | **+2.0 s** |
| 坡道移动 | 无 +2 s 高点罚时；但移动中不能开火 |
| 等待阶段微调 | 上下高点同样吃 2 s，期间按 ADR-ALERT-01 可能被看见 |

### 3.5 明确排除的数值

- 无命中率加成、无伤害倍率、无额外压制值、无「高点护甲」。
- 武器表字段不出现 `height_damage_mult` 之类。

---

## 4. 不做

- 不做向玩家暴露的连续高度数值或第三档「半高」。
- 不做高点隐藏命中/伤害/暴击倍率。
- 不做审核报告曾建议的「高点对低处命中加成」（与定位冲突，已弃用）。
- 不做纯装饰高点（无扇形差别、无代价）。

## 5. 验证用例

| ID | 场景 | 期望 |
|----|------|------|
| H-01 | 同一射手、同一朝向：谷仓二层 vs 正下方地面；主路有低掩体 | 预览扇形灰色缺口面积：高点 \< 地面的 50% |
| H-02 | 坡道格站定开火 | 允许；视线按地面档 |
| H-03 | 沿坡移动的 tick | 该单位不能开火 |
| H-04 | 队员从地面进入高点 | 移动日志含 +2 s 附加；完成前不在高点档 |
| H-05 | 高点队员 vs 地面队员，对同一岗哨锥 | 存在水平距离 D：地面不在锥内、高点在锥内（×1.5）；预览一致 |
| H-06 | 伤害日志：高点与地面对同一无掩体目标 | 命中所需发数/伤害与武器表一致，**无**高度乘区 |
| H-07 | 盲测辅助 | 教学不提示「去占高点」；截图上高点扇形阴影可辨（人工） |
