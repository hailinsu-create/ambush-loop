| 字段 | 值 |
|------|-----|
| 状态 | **草案待审** |

---

## 1. 背景

「路线需侦察」成立的前提是：被发现有**可预期代价**，且**不直接判负**。旧材料承认岗哨发现「只提示不惩罚」；若不补代价，侦察就只是跑图。

定位要求：灰盒只做视野锥 + 岗哨头顶图标，**不做数值条**；发现必须**确定性计时**（预览 = 模拟）；四档分级。规划 D2 给出秒数与代价初值，本 ADR 将其写成可测玩家规则。

工程现状仅参考，不约束本 ADR。

---

## 2. 决策

1. **四档警报（全局最高档生效）**：安静 → 起疑 → 区域警戒 → 全图警报。
2. **确定性计时**：队员（或可被发现的行为）在敌方视野锥内连续/累计待满固定秒数即升档；**不掷骰子**。
3. **代价可见**：冒险前可用「点地面，看谁能看见这里」预览谁能看见该格；区域警戒会使相关埋伏点**标红失效**且可预见。
4. **被发现不直接判负**：升至区域警戒或全图警报后，关卡至少仍保留一种可行方案（院子：A/B 至少一案仍能赢）；失败条件仍是逃脱/全灭等，而非「被看见」。
5. **表现**：视野锥 + 头顶图标表达档位；不做怀疑度数值条。

---

## 3. 规则细则（含初值）

### 3.1 档位与行为

| 档位 | 敌方行为 | 玩家可见代价 | 对「标准伏击」 |
|------|----------|--------------|----------------|
| **安静** | 行军/巡逻原路线；视野锥常态 | 无 | 可得 |
| **起疑** | 最近岗哨/巡逻**转头查看**可疑点；一段时间后若不再看见则**恢复安静** | 头顶起疑图标；转头期间锥体朝向可疑点 | 仍可得（若在恢复前未再升级） |
| **区域警戒** | **巡逻改线**；关卡标注的「相关埋伏点」**标红失效**（不可再用于布阵/站位视为暴露） | 埋伏点标红；可在侦察阶段预览「若在此被看见会废哪一点」 | **不可得**（起爆前曾达本档即失败该成就条件） |
| **全图警报** | **提前进入战斗**；后续敌人以**战斗队形**进场（不再无知行军） | 全图警报音与图标；等待阶段结束，进入战斗（非计划静默起爆） | **不可得** |

### 3.2 计时初值（规划默认）

| 参数 | 初值 | 说明 |
|------|------|------|
| 视野锥内连续暴露 → 起疑 | **1.5 s** | 单段连续计时；离开锥体则本段清零（起疑未达成时） |
| 累计暴露 → 区域警戒 | **3.0 s** | 同一侦察/等待阶段内累计（含多段进出）；达阈值升区域警戒 |
| 区域警戒下再被看到 → 全图警报 | **2.0 s** | 区域警戒期间，任意队员再在锥内累计 2 s |
| 起疑恢复 | 转头查看 **4.0 s** 后，若已无目标在锥内 → 回到安静 | 恢复期间再次满足 1.5 s 连续暴露可重新起疑或累加 |
| 高点剪影修正 | 发现距离 × **1.5**（见 ADR-HEIGHT-01） | 高点上的队员被更远锥体「看见」；计时阈值不变 |

计时与模拟同为 20 Hz；1×/2×/4× 倍速下实际 tick 数一致，结果哈希一致。

### 3.3 视野与预览

| 项 | 规则 |
|----|------|
| 看见判定 | 目标格在锥角与锥长内，且视线未被挡（高度规则见 ADR-HEIGHT-01） |
| 「点地面，看谁能看见这里」 | 显示所有当前能看见该格的岗哨/巡逻锥；与模拟判定 100% 一致 |
| 灰盒 UI | 锥体橙色；起疑/警戒/全图用头顶图标区分；**无数值条** |

### 3.4 区域警戒「埋伏点失效」初值（院子）

- 每个岗哨/巡逻在关卡 JSON 中声明 `threatens_slots[]`。
- 升至区域警戒时，这些 slot **标红失效**：已站在其上的队员不算自动暴露为全图警报，但该点失去「安全埋伏」资格（射界预览打警告；双解测试中该点方案应失败或被迫改案）。
- 玩家在侦察阶段即可看到「此锥威胁哪些点」。

### 3.5 与起爆的衔接

- 安静/起疑下，ADR-TRIGGER-01 条件可正常触发计划起爆。
- **全图警报**＝强制提前战斗：打断「静默等待→条件起爆」；敌人战斗队形进场。
- 区域警戒不自动开枪，但标准伏击已不可得；玩家仍可等条件或手动起爆。

---

## 4. 不做

- 不做概率性发现（感知检定、随机警戒）。
- 不做怀疑度/噪音数值条。
- 不做「被看见 = 立即失败」。
- 不做全图自由潜行沙盒或多职业警报技能树。
- 不做与预览不一致的隐藏发现修正（除本 ADR 与 ADR-HEIGHT-01 写明的距离倍率）。

## 5. 验证用例

| ID | 场景 | 期望 |
|----|------|------|
| A-01 | 队员在锥内连续 1.5 s | 升至起疑；岗哨转头；日志 `alert=suspicious` |
| A-02 | 起疑后离开锥体，4 s 内不再被看见 | 回到安静 |
| A-03 | 阶段内累计暴露达 3.0 s | 升至区域警戒；`threatens_slots` 标红；标准伏击标志 false |
| A-04 | 区域警戒下再被看见累计 2.0 s | 升至全图警报；敌人改战斗队形；进入战斗 |
| A-05 | 「点地面」预览：50 个采样格 | 预览「谁能看见」与模拟暴露判定一致 |
| A-06 | 院子：区域警戒触发后仍跑方案 A 与 B | 至少一案仍能胜（不因警报直接判负） |
| A-07 | 全图警报后完成关卡 | 可胜或负取决于战斗，但标准伏击判定失败 |
| A-08 | 同输入 1×/4× | 升档 tick 与日志哈希一致 |
| A-09 | 高点队员：锥长按 ×1.5 计算后 1.5 s | 在地面同等水平距离可能不起疑，高点可起疑（与 ADR-HEIGHT-01 联测） |
