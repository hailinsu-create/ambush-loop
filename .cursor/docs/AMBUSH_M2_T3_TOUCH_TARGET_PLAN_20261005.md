## 目标

验证并统一主要手机操作控件的有效点击矩形，让控件可点、互不误抢输入，同时保留现有视觉层级、命令和战术规则。

当前代码中不同控件采用不同尺寸；例如次级常驻按钮高度可能低于规划目标。本切片先以实际布局后的全局命中矩形为准建立红色测试，再只修正被证实的问题。

## 测试先行与验收

1. 在正常横屏和一个受支持的较窄合成视口强制打开触屏 HUD，等待布局完成，记录每个活动控件的有效点击区域。实施开始时确定并记录窄视口的精确尺寸。
2. 主要动作的有效热区至少约为 **48 × 48 Godot 逻辑像素**；若使用扩展热区替代，须在测试/文档中明确。图标可以小于热区。这个数值仅是逻辑坐标，不代表 48 dp 或真机拇指验收。
3. 不同活动按钮热区不互相覆盖；确认/取消面板不覆盖常驻命令行；控件留在可见安全矩形内。
4. 每个 HUD 按钮触摸由 UI 消费，不能在下方地图暂存移动/工具指令；刻意不可操作的 HUD 空白区也不能误发地图命令；WorldIntentPanel 可见时继续拦截穿透输入。
5. SETUP 中应隐藏的控件在 WATCH 不得留下隐形热区；WATCH 活动控件不得拦截 SETUP 地图点击。
6. 触摸按钮仍调用现有命令；不改变匍匐、背包、转向增量、警报、确认语义或战术状态。
7. 专项门通过后，重跑 `m2_touch_intent_gate.gd`（包括取消触摸标记）、`m2_role_dock_gate.gd`，各门均 exit 0 且 `PLAYER_DATA_UNCHANGED=1`；只有这些通过后再跑一次完整桌面 smoke。
