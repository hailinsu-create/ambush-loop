## 目标与需求来源

设计 v2 要求高度预览与结算同源。C2 只把目标特定的资格与覆盖查询迁移到高度 LOS，旧黄色连续扇形不可能精确表达混合目标高度/不连续可见区。本预研建议在 SETUP 为选中枪械队员提供独立、离散的路线目标覆盖提示，不重绘一块假连续扇形。

## 候选范围与决策

- 优先仅 main.gd 的表现层；复用 `_active_routes` / `_sample_polyline` 与 `selected.in_fire_geometry(p, grid)`，不改武器、敌我结算、资源、音频、路径或回放。
- 只表示选中、可见、存活的枪械队员；不把其他队员的覆盖并集误归给他，近战抑制这一枪械图层。既有整体 killzone 逻辑保持。
- 标注离散的具体世界目标样本，保留间断；不连成跨越未覆盖样本的面。仅表达几何射程/方向/遮挡，不暗示当前弹药、hold 或冷却已满足实际开火条件。
- 暂不新增持久几何缓存。复用现有计划编辑刷新点：选择、转向、部署/移动结束、枪械/射程、门/拓扑、关卡/重置；选人刷新需独立核查，不能假设已与 aggregate killzone 同步。运行期高度若可变，须另有明确 revision 契约。
- 使用世界坐标与同一地图变换，纯 Node2D 非交互层，不抢触摸/工具输入。镜头平移缩放应自然跟随世界，不借屏幕点击坐标计算覆盖。

## 实施确认前必须审计

1. 所有 `_refresh_killzone_preview` 调用点及 `_select_op`、旋转、移动结束、拾取换枪、门切换、阶段/关卡清理路径。
2. overlay 是否需要独立刷新频率；动态移动期间不能一直显示旧位置覆盖。
3. 既有地图绘制层级、缩放、选择标记和路线坐标，避免重叠或让标记被误读为任意连续区域。
4. 精确确认镜像 main 的原诊断差异，不把 dirty main 整文件复制进生产分支。

新增隔离表现门：平台射手/平台目标越 LOW 标记、地面 LOW 不标、FULL 不标、超射程/背向不标；另一未选中队员可射不增加当前标记；选人/旋转/移动/武器/门/重置更新；重复刷新节点数稳定。刷新前后 HP、弹药、BattleLog、sim tick、路径、位置/朝向不变。断开的覆盖段不绘制连续填充。
