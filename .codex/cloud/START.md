# Ambush Loop cloud start

1. Run `.codex/cloud/install.sh`; it pins Godot 4.7.2, verifies the official release archive's SHA-512 before extraction, and performs the required first editor import.
2. Read `AGENTS.md` and `.cursor/docs/PLANNING_INDEX.md` before editing.
3. Run destructive tests only through `ambush_loop/scripts/run_isolated_test.sh`.
4. First verify the real Accept-to-Yard transition:
   `ambush_loop/scripts/run_isolated_test.sh "$HOME/.local/bin/godot" accept_cta_flow_gate.gd`
5. For gameplay changes, run the relevant focused gate and then the full smoke through the same wrapper.
6. Cloud results are desktop/headless evidence only. Android APK, touch, audio, memory, and vivo device acceptance remain local gates.
7. Never commit APKs, signing files, secrets, device logs, or personal phone data.
8. Run `.codex/cloud/install-look.sh` in environment setup for pinned Blender 5.2.2 and glTF tools. Installers accept `AMBUSH_TOOLS_DIR` (default `$HOME/.local`) and `AMBUSH_DOWNLOAD_CACHE`; put its `bin` directory on PATH. Never change HOME to redirect installation. Use `.agents/skills/paperroute-game-build/SKILL.md` for Look work; preserve the existing ArtSource pipeline and Engine/Look separation. Linux graphics-library dependencies and actual rendering must be checked in the published environment.
9. Use `.agents/skills/ambush-web-gpt-review/SKILL.md` and `.codex/cloud/WEB_REVIEW.md` for external PLAN/REVIEW. Verify exact source revision before accepting any response; the old local connector does not automatically follow this branch.
10. Rerun the Look installer after updating to refresh `blender-headless`. Its Python launcher starts an authenticated private Xvfb/OpenGL display and reaps Xvfb and Blender on normal exit, Python failure, SIGINT, SIGTERM, or timeout. `AMBUSH_BLENDER_THREADS` defaults to 2; `AMBUSH_BLENDER_TIMEOUT` defaults to 900 seconds. Timeout returns 124; cancellation returns 130/143; other Blender failures remain nonzero. Both Xvfb and xauth are required. Run generators in a fresh temporary copy of ArtSource; require exit code 0 and all new outputs. Files alone never imply success.
11. `.codex/cloud/environment-setup.sh` executes its sibling installers and launcher from the same code package, without fetching an old embedded pin. The saved environment setup must select the intended immutable commit for the whole `.codex/cloud/` directory. Preserve verified download caches and installed tools in the snapshot; no service process must survive it. Keep the network policy unchanged; if a missing archive's official host is denied, report the missing artifact rather than bypassing the proxy or changing domains.
12. Run actual process lifecycle checks with `python3 .codex/cloud/test-look-runtime.py /absolute/path/to/blender-headless /temporary/evidence/directory`. This Linux test uses real Blender/Xvfb, verifies distinct concurrent displays, failure/timeout/cancellation codes, and detects unreaped children belonging to the test. Also run a complete generator and `gltf-transform inspect`; lifecycle tests alone do not validate rendering.
